# 🎂 Python Birthday & Life Countdown Calculator
生日倒數與人生時間計算器！

## 🚀 如何執行

1. **直接下載這個專案**
   有兩個py檔
   -main.py
   -bday-messages
   同時在一個視窗開啟!
   

3. **修改你的生日資訊**
   打開 `main.py`，有兩個地方需要把裡面的日期改成你自己的生日：
   next_birthday = datetime.date(2027, 7, 3) # 你的下一次生日
   birth_year = 1994                          # 你的出生年份
   birth_month = 7                            # 你的出生月份
   birth_day = 3                              # 你的出生日期
   

4. **執行程式 (Run the code)**
